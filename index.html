La composition d’une URL

L’adresse suivante est l’URL d’une page d’un site :

http://www.monsite.com/chemin/vers/fichier.html
1. Le protocole

Généralement HTTP ou sa version sécurisée HTTPS. Le protocole indique la façon dont le navigateur échange les données avec le serveur.

2. Le nom de domaine

www.monsite.com désigne le serveur Web auquel le navigateur s’adresse.

3. Le chemin d’accès

/chemin/vers/ indique l’emplacement de la ressource dans les dossiers du serveur.

4. Le nom du fichier

fichier.html est la ressource visée. Des informations optionnelles peuvent suivre un point d’interrogation.

À retenir : le protocole est toujours suivi des signes ://. Les différents éléments de l’adresse sont ensuite séparés par une barre oblique /.
