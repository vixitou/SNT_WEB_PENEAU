Variables disponibles

La variable capteur contient la mesure du capteur. Dans les défis du robot, tu peux écrire angle = 90 ou vitesse = 50 dans le programme : le robot et les affichages prennent alors ces valeurs. Les curseurs restent utilisables si tu ne fixes pas ces variables dans le code.

Actionneurs à commander

Python accepté dans ce simulateur

Tu peux utiliser les variables, les nombres, True, False, if, else, les calculs simples (+, -), les comparaisons (>, <, ==) et print(). Exemple : angle = angle + 1. Respecte l'indentation de 4 espaces. Ce simulateur comprend un petit sous-ensemble de Python, pas toutes les fonctionnalités du langage.
